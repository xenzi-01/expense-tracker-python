
# expense-tracker-python

A simple command-line expense tracker written in Python.

## Features
- Add expenses with a description and amount
- View all expenses and the total
- Delete expenses
- Data saved to a local JSON file
- Categorize expenses (food, transport, bills, shopping, other)
- Spending summary by category with percentages

## How to run
python main.py
